## Probador de DOMINO
`FINANCO_Probador_DOMINO.html` es una página de prueba para chatear con DOMINO desde el teléfono. Usa el mismo motor y las mismas preguntas que el asistente real, muestra cómo le llega la consulta al asesor y **no envía nada** a la hoja ni al Hub. Sirve para compartir el enlace con la mesa directiva. Se regenera con `build_probador.py` (en la carpeta del motor DOMINO) cada vez que cambian las preguntas.
